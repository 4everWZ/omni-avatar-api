# 工作站后台 Responses 读图验收

现有 Qwen3.5 9B 检查点含视觉权重。原部署使用语言模式，网关的计量和生成均拒绝一张图片。启用视觉后复用原模型卷，仍使用 `llm-default`。后台网关和引擎滚动替换期间，前台模型进程持续运行。

第一次读图计量成功，但带图生成返回 500。后台引擎记录图像预处理缓存未命中。私有引擎直调 Responses 能读同一类图，因此把容量计量调用改为跳过图像缓存，只在正常生成时使用该缓存。

- 红、蓝对照各重复两次。四次 Responses 生成均正确识别颜色，计量值与生成用量均为 93 输入 tokens。
- 同一网关的纯文本 Responses 仍返回结构化结果。模型卡实报前台 8192、后台 262144。后台待机显存从 18189 MiB 到 18773 MiB，此次增量 584 MiB。
- 同时发起真实前台问候与后台两张 P2 主帧观察。前台 0.82 秒、后台合计 1.87 秒，请求时段重叠 0.82 秒。两帧调用均完成且计量相符。1.48 秒读到人物和红色帽饰，10.44 秒主要读到画面文字，不能据此判定选材质量或持续吞吐。
