# 工作站部署与验收计划

双 RTX 3090 提供共享推理与 Avatar API。应用负责用户、长期记忆、Agent／Swarm 编排、工具执行和工作区操作。服务职责见[架构](../architecture.md)，参数与生命周期见 [API](../api.md)，当前部署和实测数据见[工作站指南](../deployment/workstation.md)。

## 已完成里程碑

| 阶段 | 交付内容 | 验证覆盖 |
| --- | --- | --- |
| 推理与 Ava 2D | GPU 1 原生 Omni；GPU 0 长上下文 LLM；CPU Ava；独立鉴权与准入。 | Responses 增量 SSE、结构化、工具结果续接、约 22K 多轮检索、约 20 分钟双工与 2D 共驻。 |
| 四路并发与混跑 | 单请求 262144；四个生成序列；共享 token 预算；解码 CUDA Graph。 | 四路输出区间重叠、长短请求混跑、独立历史续接、预算压力及取消释放。 |
| 默认推理策略 | Chat／Responses 默认 CoT、上游思考预算；Realtime 默认 basic 8000／6000，调用方可在创建会话时配置。 | 默认完整答案、显式覆盖、思考预算、JSON Schema、function 调用及归属续接。 |

性能条件、TPS 与原始证据统一由工作站指南维护；接口默认值与可调字段由 API 契约维护。

## 后续验收

1. **浏览器实物交互**：通过 localhost SSH 隧道验证麦克风、屏幕、实际扬声器播放、主观口型、静默、插话和恢复。记录设备、浏览器及交互结果。
2. **可信 HTTPS**：由 tailnet 管理员启用 Serve，配置私网 HTTPS，验证浏览器权限与 WHEP 的 VPN 直连。
3. **完整 262K 窗口**：构造接近单请求上限的多轮历史，记录输入／输出预算、早期事实检索、首增量、显存及取消释放。长短请求混跑继续按总 token 预算准入；多路满窗口作为独立容量评估，结合量化、模型与硬件分工测量。
4. **默认 CoT 长历史质量**：以当前默认策略复验 Omni 约 8K 和后台长历史，分别记录思考与正文、完整答案及历史保留。
5. **持续负载**：按应用确定的请求长度、调用强度和通话时长评估 QoS；当前功能验收周期约半小时。

外部 Swarm／orchestrator 通过 Responses provider 接入，应用项目持有各 worker 的历史分支与工具循环。未来 3D 多视角驱动沿用现有 Avatar 注册、音频、代次与媒体接口。
